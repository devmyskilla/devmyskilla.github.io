# دنيا الدورات — Platform Directory Pro 2.0

دليل لاكتشاف ومقارنة منصات التعلم، منشور كواجهة ثابتة على GitHub Pages مع بيانات منصات من Supabase ونسخة محلية احتياطية.

## تطوير
**اتحاد شباب الأمة**

## بنية الصفحات
- **`index.html`:** صفحة رئيسية تعريفية شبابية تشرح ما هي دنيا الدورات، لماذا أنشئت، كيف تعمل، ومن طوّرها، وتعرض إحصائيات حية من نفس مصدر بيانات المنصات.
- **`explore.html`:** تطبيق اكتشاف المنصات الكامل: البحث، الفلاتر، التصنيفات، المميزة، المفضلة، الأخيرة، المقارنة، الاختبار، والمنصة العشوائية وبناء المسار.
- **`platform.html`:** ملف مستقل لكل منصة، مع العودة إلى صفحة الاستكشاف.
- **`course.html`:** يحافظ على توافق الروابط القديمة ويحوّلها إلى صفحة المنصة.

## المعمارية
- **GitHub Pages:** يستضيف HTML/CSS/JavaScript وPWA.
- **Supabase:** المصدر المفضل لبيانات المنصات العامة مثل الوصف، الفئة، اللغات، حالة المجاني والشهادة، والعدد الرسمي عند توفر تحقق مصدره موثوق.
- **`js/data.js`:** fallback محلي عند تعذر الوصول إلى Supabase، ويكمل حقول العرض الناقصة فقط.
- **`js/landing.js`:** منطق الصفحة الرئيسية فقط: الإحصائيات الحية، اللغة، الثيم، وروابط الانتقال إلى الاستكشاف.
- **`js/app.js`:** منطق تطبيق اكتشاف المنصات في `explore.html`.
- **RLS:** القراءة العامة لجدول `platforms` مقيدة بالصفوف ذات `status = 'active'`.
- **المفتاح الأمامي:** يستخدم الموقع publishable key فقط؛ لا يوجد `service_role` أو secret key في المستودع.
- **LocalStorage:** المفضلة، المقارنة، سجل المشاهدة، اللغة والثيم تبقى على جهاز المستخدم.

## أهم الميزات
- صفحة رئيسية تشرح المشروع والمشكلة التي يحلها والجهة المطورة قبل الدخول إلى الدليل.
- بحث متعدد اللغات داخل الاسم والوصف والتصنيف واللغة.
- فلاتر المجال واللغة ونموذج السعر وحالة التحقق والمحتوى المجاني والشهادات.
- بطاقات منصات تعرض البيانات المهمة لاتخاذ القرار بدون اختراع أرقام غير موثقة.
- مقارنة حتى 3 منصات مع ترحيل آمن للحالة المحلية القديمة.
- صفحة Profile مستقلة لكل منصة عبر `platform.html?id=plat-N`.
- اختبار لترشيح المنصة الأنسب ومولد مسارات تعليمية.
- العربية والإنجليزية والتركية.
- Dark / Light Mode.
- PWA v7 + Service Worker + Offline fallback للصفحة الرئيسية والاستكشاف وصفحات المنصات.
- Responsive مع تحسينات وصول للوحة المفاتيح والحوارات والتبويبات.

## سلامة البيانات
- لا يُعرض `0` عندما يكون العدد الرسمي غير معروف.
- لا تُسمى المحاكاة أو الوحدات أو المسارات أو الشهادات «دورات».
- `expected_count` و`expected_count_type` و`last_verified` لا تُملأ من عدد السجلات المحلية.
- بيانات Supabase الموثقة لا تُستبدل ببيانات fallback الأقدم.
- الصفحة الرئيسية تستخدم نفس طبقة البيانات المطبعة التي يستخدمها دليل الاستكشاف، ولا تحتفظ بأرقام ثابتة منفصلة.

## التطوير والتحقق
الاختبارات تستخدم Node.js المدمج `node:test`، ويشغّل GitHub Actions:

```bash
node --test tests/*.test.cjs
for f in js/*.js; do node --check "$f"; done
node scripts/build-platform-seed.mjs > /tmp/platform-directory-seed.sql
diff -u supabase/platform-directory-seed.sql /tmp/platform-directory-seed.sql
git diff --check
```

كما يتحقق CI من القراءة العامة الحقيقية من Supabase باستخدام publishable key قبل اعتبار الفرع جاهزًا للإصدار.

## قاعدة البيانات
تعريف توسيع بيانات المنصات محفوظ في:
- `supabase/platform-directory.sql`
- `supabase/platform-directory-seed.sql`

الـseed يملأ بيانات العرض الآمنة باستخدام `COALESCE` ولا يكتب حقول العدد أو تاريخ التحقق الرسمي.

## الخصوصية
لا يحتاج الموقع حساب مستخدم. المفضلة والمقارنة وسجل المشاهدة والثيم واللغة تحفظ محليًا في المتصفح.
