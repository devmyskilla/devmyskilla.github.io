# دنيا الدورات — Client-only Upgrade

نسخة مطورة تعمل بالكامل بدون Backend ومناسبة للنشر على GitHub Pages.

## تطوير
**اتحاد شباب الأمة**

## الميزات المضافة
- صفحة تعريفية كاملة بالمشروع وهوية المطورين.
- بحث ذكي داخل الاسم والوصف والتصنيف واللغة.
- فلاتر اللغة والتصنيف والمجاني والشهادة.
- ترتيب النتائج حسب الملاءمة، الاسم، المجاني، المشاهدات، وآخر مشاهدة.
- المفضلة عبر LocalStorage.
- آخر المنصات مشاهدة عبر LocalStorage.
- عداد مشاهدة محلي وترتيب Trending على الجهاز.
- مقارنة حتى 3 منصات.
- اختبار لاختيار المنصة الأنسب.
- مولد مسارات تعليمية جاهزة لخمس أهداف.
- زر منصة عشوائية.
- مشاركة باستخدام Web Share API أو نسخ الرابط.
- Dark / Light Mode.
- أقسام Featured وإحصائيات مباشرة من data.js.
- تصميم Responsive وحركات دخول مع دعم reduced-motion.
- PWA + Service Worker + Offline fallback.
- العربية والإنجليزية والتركية.

## النشر
ارفع جميع الملفات إلى جذر الفرع الذي تنشر منه GitHub Pages. لا تحتاج Node.js أو قاعدة بيانات أو مفاتيح API.

## ملاحظة الخصوصية
المفضلة، المقارنة، المشاهدات، الثيم، واللغة تحفظ في LocalStorage على جهاز المستخدم فقط.
